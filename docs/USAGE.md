# 使用说明

## 导入视觉对象

从 GitHub Releases 下载 `.pbiviz`，在 Power BI Desktop 的“可视化”窗格中选择“从文件导入视觉对象”。导入后会出现“高性能帕累托图”图标。

升级已有版本时，请导入版本号更高的 `.pbiviz` 并确认替换。如果字段槽没有立即刷新，移除相应字段后重新拖入。

## 添加字段

### 门店

放入需要排序的实体字段，例如门店 ID、客户 ID、SKU 或产品名称。该字段决定每个帕累托点代表什么。

### 销售额

放入需要进行降序排序与累计的度量。视觉对象使用字段槽中的第一个度量，并忽略空值、零值和负值。

### 工具提示

可以同时放入多个文本字段、日期字段或度量。视觉对象会按照模型格式显示这些值，例如门店名称、省份、城市、订单数、同比、环比或客单价。

分类字段最好与“门店”字段保持一对一或多对一关系，避免同一实体被展开成多行。

## 格式设置

- **曲线**：设置颜色和线宽。
- **坐标轴**：设置网格线和字号。
- **数据标签**：设置是否显示累计占比标签、标签数量和字号。
- **占比参考线**：绘制累计占比横线；`0.8` 表示 80%。
- **数量参考线**：绘制实体排名竖线；例如 `1000` 显示 `X = 1,000`。

## Tooltip

默认 Tooltip 包含实体、指标值、排名和累计占比。放入“工具提示”字段槽的值会追加显示。

视觉对象同时声明了默认、现代和报表页 Tooltip 支持。使用报表页 Tooltip 时，Power BI 会根据当前悬停实体的选择标识筛选 Tooltip 页面。

## 大数据量

视觉对象每个数据窗口请求最多 30,000 行。如果 Power BI 指示还有数据，视觉对象会调用 `fetchMoreData(true)` 继续加载，并在右上角显示当前加载数量。

分段全部返回后才是完整曲线。若触及 100 MB DataView 内存限制，视觉对象会提示曲线可能不完整。
